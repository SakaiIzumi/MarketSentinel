# 知界 · Knowledge Universe

完全本地运行的 Android 学习 App，涵盖天文、地理、历史、文学、信息安全和英语。

## 隐私设计
- AndroidManifest 不声明 INTERNET 权限；运行时不调用远程 API、不上传数据、不做云同步。
- 账户、学习进度、收藏、笔记和测验记录保存在应用私有目录的 SQLite 数据库。
- 密码以每账户随机盐和 PBKDF2WithHmacSHA256（210,000 次迭代）派生值保存，不存明文。
- 账户只用于区分本机学习档案，并非云账号；卸载或清除数据会删除学习记录。
- Gradle 首次构建仍需要下载 Android 构建依赖；安装后使用不需要网络。

## 功能
- 本地注册、登录、退出；六大学科离线知识卡和关键词搜索
- 阅读完成、学习时长、学习统计；收藏、个人笔记、快速测验和答题记录
- 深色主题、学科图标、底部导航

## 构建
使用 Android Studio 打开本目录，JDK 17、Android SDK 35，等待 Gradle Sync 后运行 app。
